01 / 소개

정확함과
꼼꼼함을 기준으로

금융 서비스는 작은 화면 차이도 사용자의 이용 경험에 영향을 줄 수 있다고 생각합니다.

웹에이전시 삼도리에서 2023년 11월부터 2026년 3월까지 웹퍼블리셔로 근무하며, 은행과 카드사 프로젝트를 중심으로 웹 화면을 구현했습니다. 기획서와 디자인 시안을 바탕으로 UI를 제작하고, 다양한 화면 환경에서 발생하는 레이아웃 오류와 스타일 충돌을 점검하며 작업했습니다.

04 / 업무 방식

작은 오류도
끝까지 확인합니다.

요구사항부터 검수까지, 단계별 확인을 통해 화면의 일관성을 지킵니다.

  1. 01

    요구사항과 시안 확인

    기획 의도와 화면 구성을 파악하고 필요한 공통 요소를 정리합니다.

  2. 02

    마크업 및 UI 구현

    HTML·CSS를 중심으로 화면을 구성하고 필요한 인터랙션을 적용합니다.

  3. 03

    원인 확인과 수정

    오류 발생 시 마크업 구조, CSS 우선순위와 스타일 충돌 등을 확인합니다.

  4. 04

    수정 후 영향 범위 점검

    변경한 부분이 다른 화면이나 요소에 영향을 주지 않는지 함께 확인합니다.
